# 验证状态矩阵

> 最近同步：2026-09-14。此页区分代码能力、自动测试、真实外部验证和目标环境验收；“已实现”不等于“生产已完全就绪”。

## 证据等级

| 等级 | 含义 |
|---|---|
| 代码支持 | 接口和实现存在，可能只有模拟测试 |
| 自动验证 | 普通CI使用本地夹具、占位密钥或临时进程验证 |
| 外部单次验证 | 曾用真实凭据/服务验证；不进入CI，不承诺长期稳定 |
| 目标环境验收 | 在正式域名、代理、持久卷和真实容量下完成验收 |

## 当前状态

知乎OAuth与公共匹配已增加实现及模拟供应商测试；游客公共匹配和房间邀请已实现。知乎OAuth目标回调为`https://airoundtable.stream/api/auth/zhihu/callback`，真实授权与跨设备匹配仍待验收。配置和限制见[知乎登录与公共匹配](../operations/zhihu-login-matchmaking.md)。

| Socket、会话、SQLite、主动恢复 | 自动验证；含SIGKILL/WAL/备份恢复 | 磁盘写满、宿主断电、网络存储 |
| 题库 | 默认6道原创讨论题，无平台请求；可选知乎题源保留11候选、9核验题及动态推荐 | 模型发言仍需模型服务；外部题源额度与审核边界不变 |

| DeepSeek | `deepseek-v4-flash`七动作单次真实验证；接入及failover代码自动验证 | 长期错误率、SLA、成本、容量、真实故障注入 |
| 内容安全 | 基础隐私、凭据、提示注入和隐藏身份规则自动验证 | 不是完整政治、暴力、色情、仇恨、自伤或违法审核系统 |

| Docker与Compose | GitHub Actions构建和配置解析 | 没有部署到正式域名和持久卷 |
| 临时 Compose 集成 | CI 启动隔离 app 容器，健康检查、首页、备份文件和重启 | 非公网、无真实用户/供应商；不证明正式域名、Caddy/CDN 或容量 |
| 临时公网隧道 | 按[临时验收](../operations/temporary-acceptance.md)由人工执行后记录证据 | 当前仓库未声称已完成；需逐次记录地址、时间和结果 |
| 管理员API | 自动测试、生产进程冒烟、结构化审计、Token指纹限流、版本确认；公共Caddy入口阻断管理员路径 | VPN、防火墙、IP allowlist、角色权限、集中审计和Token轮换仍需正式环境 |

“生产题目”只表示位于`productionTopicPacks`、允许生产题目提供器轮换，不表示整个系统已经完成公网生产验收。

GitHub Actions不使用真实知乎、GLM或DeepSeek凭据。CI中的生产冒烟显式使用静态题目和占位模型Key，不触发真实外部调用。

## 公网发布门槛

- 真实域名、TLS、Caddy/CDN链路与可信代理IP验证。
- 目标服务器资源和完整多人长局压测。
- 经批准的完整内容审核、下架和申诉流程；动态题目的模型生成共识与默认答案在公开运行前必须纳入该流程。
- 真实备份保留、异地恢复、磁盘故障和告警演练。
- 管理员路由的网络层隔离、Token轮换和操作审计。
- 面向用户发布隐私声明和AI处理告知。
