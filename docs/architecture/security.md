# 公网安全边界

> 当前分支实现基础Socket防护；仍需在真实反向代理和部署环境中压测。

## 握手与来源

生产环境必须设置逗号分隔的`ALLOWED_ORIGINS`，只接受规范化HTTP/HTTPS origin精确匹配；没有Origin的Socket握手默认拒绝。开发模式允许无Origin测试客户端，并默认允许localhost与127.0.0.1当前端口。

默认`TRUST_PROXY_HOPS=0`，忽略`X-Forwarded-For`。部署在固定反向代理之后才按实际代理层数设置；配置错误会让限流使用错误地址。解析只接受合法IP，不接受主机名或任意文本。

## 默认限制

| 范围 | 限制 |
|---|---:|
| 单IP同时Socket连接 | 20 |
| 单IP创建房间 | 5次/分钟 |
| 单IP加入/恢复 | 20次/分钟 |
| 单会话命令与同步 | 20次/10秒 |
| 未认证连接 | 30秒后关闭传输并允许客户端正常重连 |
| 单Socket消息 | 16 KiB |
| 内存限流桶 | 10,000；满时回收过期桶，否则拒绝新键 |

限流器是单进程内固定窗口实现。P0按单Node实例部署；多实例时必须迁移到共享限流存储或在入口网关统一限流。

会话过期或撤销后，命令、同步和广播都会停止；客户端收到`session:expired`并清除本地Token。连接数在断开时释放，未认证连接不会永久占用配额。

## 健康检查

- `GET /api/health/live`：Node进程可处理HTTP即返回200。
- `GET /api/health/ready`：活动房间恢复和会话清理初始化完成后返回200；关闭期间返回503。
- 响应禁止缓存，不包含数据库路径、版本、密钥或内部错误。

## 尚未覆盖

公网DDoS必须由CDN或反向代理处理；应用内限制不能替代网络层防护。基础结构化脱敏日志和Caddy安全Header已实现，仍需真实代理测试、压力测试和外围防护验收。
