# 内容安全边界

## 已实现

`src/safety/content-policy.ts`为真人输入、AI输出、人工TopicPack和知乎回答片段提供统一的确定性基础检查：

- Unicode NFC规范化，将全角英文字母/数字转为半角。
- 移除零宽、双向控制和不可见控制字符，压缩空白。
- 拒绝HTTP URL、邮箱、手机号及常见微信/QQ联系方式。
- 拒绝常见Bearer/API Key/私钥形式。
- 拒绝要求忽略指令、输出系统提示或开发者消息的提示注入。
- AI输出额外拒绝身份表、普通人和影子隐藏身份泄露。
- 允许游戏规则需要的“某席是AI”指认和真人对自身身份的声明。

真人内容在进入GameState和公开日志前检查；拒绝返回`CONTENT_REJECTED`，不保存或记录原文。AI内容在结构化JSON解析后检查，失败触发供应商failover，最终由阶段默认内容兜底。

题目包全部公开文本在加载时检查。知乎回答按赞同数排序后逐条检查，不安全的高赞候选会跳过；没有安全回答则该题核验失败，不修改原文强行通过。

Prompt明确将题目、回答和玩家发言标记为不可信数据，模型不得执行其中指令。

## 不是安全保证

当前实现是基础隐私和提示注入过滤，不是完整内容审核系统。它不能可靠识别所有政治、暴力、色情、仇恨、自伤、违法或变体表达，也不能保证模型永不泄露隐藏信息。

公开运行前仍需接入经批准的审核能力，建立题目人工复核、申诉和下架流程，持续运行真实模型对抗测试，并确保审核日志不保存完整敏感文本、凭据或个人信息。
