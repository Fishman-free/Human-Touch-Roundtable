# 浏览器应用

> 2026-09-10：Next.js页面、自定义Node服务器和开发适配器已实现，生产构建通过。

## 页面流程

单页应用覆盖：创建/加入房间、玩家/观战模式、全员准备、题目准备、三轮回答、顺序辩论、公开投票、身份揭示及完整日志。

页面只消费Socket网关返回的裁剪视图。身份、有效票和供应商状态不在客户端推算；所有按钮是否可用以服务端`actions`为准。

## 会话

sessionToken保存在`sessionStorage`而非URL。同一标签页刷新后自动执行`room:resume`；不同标签页具有独立会话，方便同一浏览器模拟不同真人。点击退出会清除当前标签页凭据并重连Socket，但不会释放本局座位。

## 开发外部能力

- `StaticTopicProvider`提供两组人工整理的知乎题目材料和默认答案。它没有调用知乎接口，只用于打通游戏流程。
- `MockAiProvider`覆盖三轮回答、指认、回应、追问和投票，并模拟650至1370毫秒延迟。
- 模拟AI知道服务端角色表，优先在辩论中指认影子、投票干扰普通人；最终动作仍经过游戏核心校验。

## 服务入口

`server.ts`先准备Next，再把Socket.IO附着到同一个HTTP服务，最后通过`createServerContext`接入SQLite。默认监听`0.0.0.0:3000`。

开发模式允许固定本地会话密钥；生产模式未提供至少32字节的`SESSION_HMAC_KEY`会拒绝启动。数据库父目录由启动入口创建，默认路径为`./data/roundtable.db`。
